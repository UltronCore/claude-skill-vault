# Notion Dashboard Designer Skill

## Purpose
Build a simple Notion homepage from several related databases.

## Use when
A user wants a hub, command center, portal, trip page, project page, or shared workspace.

## Workflow
1. Define the main daily actions.
2. Add links to every key database.
3. Add sections for Today, Upcoming, Needs Action, Budget, and Notes.
4. Use short labels and mobile friendly sections.
5. Add an update log at the bottom.

## Output
Return the dashboard sections, linked views, filters, and open questions.
