# Notion QA Auditor Skill

## Purpose
Review a Notion workspace for missing fields, unclear statuses, duplicate databases, weak views, and unfinished setup.

## Use when
A user asks to QA, clean up, finish, audit, organize, or improve an existing Notion base.

## Workflow
1. List every database and page.
2. Check whether each database has title, status, date, owner, priority, notes, and links where useful.
3. Check if views match real workflows.
4. Find missing starter rows and unclear labels.
5. Mark placeholders that need research or user input.

## Output
Return fixes made, issues found, and next improvements.
