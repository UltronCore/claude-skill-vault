# Notion View Builder Skill

## Purpose
Build useful views for Notion databases.

## Use when
A user wants tables, boards, calendars, galleries, lists, or filtered views.

## Workflow
1. Choose the main question the view should answer.
2. Pick table, board, calendar, list, gallery, or timeline.
3. Filter by status, owner, date, priority, or category.
4. Sort by date first, then priority.
5. Show only the fields needed for that view.

## Output
Return view names, filters, sorts, grouping, and visible fields.
