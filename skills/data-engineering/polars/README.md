# Polars DataFrame Library

Fast in-memory DataFrame library for 1-100GB datasets. Uses Rust-based engine with lazy evaluation, query optimization, and Arrow columnar memory format.

## Activation
`/polars` — activate when working with data processing, large DataFrames, or pandas performance issues.

## Key Capabilities
- Lazy vs eager evaluation strategies
- Expression API for transformations
- Scan/read large files (Parquet, CSV, JSON)
- Multi-threaded query execution
- Interop with pandas, Arrow, NumPy
