# Data Engineering Skills

This directory contains 15 skills for building data pipelines, data warehouses, streaming architectures, and ML feature infrastructure.

## Skills in this category

| Skill | Description |
|-------|-------------|
| [airflow-dag-patterns](airflow-dag-patterns/SKILL.md) | Build production Apache Airflow DAGs with best practices for operators, sensors, and testing |
| [async-python-patterns](async-python-patterns/SKILL.md) | Implement async Python applications with asyncio and concurrent programming patterns |
| [data-lakehouse-architecture](data-lakehouse-architecture/SKILL.md) | Build data lakehouses with Delta Lake, Apache Iceberg, and Apache Hudi on Spark and Trino |
| [data-pipeline-engineer](data-pipeline-engineer/SKILL.md) | Build scalable data pipelines with Apache Spark, dbt, Airflow, and cloud-native platforms |
| [data-versioning-dvc](data-versioning-dvc/SKILL.md) | Version datasets, models, and ML pipelines with DVC and integrate with Git/CI |
| [database-cdc-patterns](database-cdc-patterns/SKILL.md) | Stream database changes with Debezium, PostgreSQL logical replication, and Supabase Realtime |
| [database-schema-designer](database-schema-designer/SKILL.md) | Design database schemas, plan migrations, optimize queries, and choose between SQL and NoSQL |
| [drizzle-orm](drizzle-orm/SKILL.md) | Type-safe database access with Drizzle ORM for TypeScript |
| [feature-store-engineering](feature-store-engineering/SKILL.md) | Build ML feature stores with Feast or Tecton covering offline/online sync and point-in-time joins |
| [graphql-expert](graphql-expert/SKILL.md) | Design and implement GraphQL APIs with type safety, resolvers, and federation |
| [mlops-engineer](mlops-engineer/SKILL.md) | Build comprehensive ML pipelines, experiment tracking, and model registries with MLflow and Kubeflow |
| [polars](polars/SKILL.md) | Fast in-memory DataFrame processing with Polars — lazy evaluation and Apache Arrow backend |
| [sql-expert](sql-expert/SKILL.md) | Database design principles, schema design, indexing strategy, ORM selection, and serverless databases |
| [statistical-analyst](statistical-analyst/SKILL.md) | Run hypothesis tests, A/B analysis, sample size calculations, and statistical significance interpretation |
| [websocket-realtime](websocket-realtime/SKILL.md) | Build real-time WebSocket applications for live data streaming and bidirectional communication |
