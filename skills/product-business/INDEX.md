# Product Business Skills

_Last updated: 2026-05-08_

Skills for product management, business strategy, and executive advisory.

| Skill | Description | Version | Status |
|-------|-------------|---------|--------|
| [Agile Product Owner](agile-product-owner/) | Story writing, backlog refinement, sprint planning | v1 | ✅ active |
| [CEO Advisor](ceo-advisor/) | Strategic CEO advisory: vision, growth strategy, stakeholder management | v1 | ✅ active |
| [Competitive Teardown](competitive-teardown/) | Deep competitive analysis: feature comparison, positioning, gaps | v1 | ✅ active |
| [CTO Advisor](cto-advisor/) | Technology strategy: tech roadmap, architecture governance, build vs buy | v1 | ✅ active |
| [Founder Coach](founder-coach/) | Startup coaching: fundraising, team building, pivots | v1 | ✅ active |
| [Investor Materials](investor-materials/) | Pitch decks, one-pagers, financial models | v1 | ✅ active |
| [Product Discovery](product-discovery/) | User research, problem definition, opportunity sizing | v1 | ✅ active |
| [Product Strategist](product-strategist/) | Product strategy: vision, positioning, roadmap, metrics, OKRs | v1 | ✅ active |

## Usage Patterns

- **C-level strategy**: Use `cto-advisor` or `ceo-advisor` for strategic guidance
- **Product work**: Use `product-discovery` → `product-strategist` → `agile-product-owner` pipeline
- **Competitive intel**: Use `competitive-teardown` for market analysis
- **Fundraising**: Combine `founder-coach` + `investor-materials`
