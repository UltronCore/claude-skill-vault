# private-repo-backup

**Category:** automation
**Status:** active
**Version:** v1

## What it does
Auto-backup workflow skill — maps personal client repos and defines when/where to push each type of work.

## When to use
- Starting a new coding session across multiple repos
- After making changes, to know which remote to push to
- To get consistent commit/push behavior across projects

## Note
This skill references personal project paths and client names. Considered personal-use only.
