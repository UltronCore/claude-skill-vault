# Compliance Skills

_Last updated: 2026-05-08_

Skills for regulatory compliance, security frameworks, and risk management.

| Skill | Description | Version | Status |
|-------|-------------|---------|--------|
| [GDPR Expert](gdpr-expert/) | GDPR/DSGVO compliance: data mapping, privacy notices, consent flows | v1 | ✅ active |
| [ISO 27001 ISMS](iso27001-isms/) | ISO 27001 Information Security Management System | v1 | ✅ active |
| [Risk Management](risk-management/) | Enterprise risk management: risk registers, FAIR framework | v1 | ✅ active |
| [Security Pen Testing](security-pen-testing/) | Penetration testing: OWASP, PTES, reporting | v1 | ✅ active |
| [SOC 2 Compliance](soc2-compliance/) | SOC 2 Type II: controls, evidence gathering, audit prep | v1 | ✅ active |

## Usage Patterns

- **Privacy compliance**: Start with `gdpr-expert` for EU data handling
- **Security audit**: Use `soc2-compliance` or `iso27001-isms` depending on framework
- **Risk work**: `risk-management` for ongoing ERM; `security-pen-testing` for technical testing
- **Full security posture**: Combine `iso27001-isms` + `risk-management` + `security-pen-testing`
