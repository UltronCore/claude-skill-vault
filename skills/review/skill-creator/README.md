# Skill Creator

**Source:** Anthropic Agent Skills Marketplace
**Category:** review

## Description

Create new skills, modify and improve existing skills, and measure skill performance. Handles skill creation from scratch, editing, optimization, running evals, benchmarking performance with variance analysis, and optimizing skill descriptions for triggering accuracy.

## Trigger Phrases

- "create a new skill"
- "edit this skill"
- "run evals on this skill"
- "optimize skill triggering"
- "benchmark skill performance"

## Files

- `SKILL.md` — main skill definition
- `agents/` — agent configurations
- `assets/` — skill assets
- `eval-viewer/` — evaluation viewer tool
- `references/` — reference materials
- `scripts/` — utility scripts
- `LICENSE.txt` — license terms
