# Theme Factory

**Source:** Anthropic Agent Skills Marketplace
**Category:** ui-ux

## Description

Toolkit for styling artifacts with themes. Applies to slides, docs, reports, HTML landing pages, and more. Includes 10 pre-set themes with colors and fonts, plus on-the-fly theme generation.

## Trigger Phrases

- "apply a theme to this"
- "style this document"
- "give this a dark theme"
- "make this look professional"
