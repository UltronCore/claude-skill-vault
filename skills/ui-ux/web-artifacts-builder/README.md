# Web Artifacts Builder

**Source:** Anthropic Agent Skills Marketplace
**Category:** ui-ux

## Description

Suite of tools for creating elaborate, multi-component claude.ai HTML artifacts using React, Tailwind CSS, and shadcn/ui. Use for complex artifacts requiring state management, routing, or shadcn/ui components — not for simple single-file HTML/JSX.
